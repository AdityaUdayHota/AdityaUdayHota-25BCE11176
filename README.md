## Overview
The aim of my project is to provide a technical relief to small-town shopkeepers in our country. The information in the data storage will be;
- Date of the account change
- Type of change(income or expense)
- Amount of money
- Category or reason
## Features
- The code is designed to perform multiple tasks such as entering , viewing and deleting financial records.
- The design is simple , yet efficient and easy to understand for the users.
- the program to view all financial records is prepared , whereas , the program to delete all financial records is not , due to security reasons.
## Tools used
- IDLE (python 3.11 64-bit)
- CSV file (imported from python)
## Steps to use
- The project can be acquired from the Github website.
- It should be run using Python in the computer.
## Instructions for testing
- For a mock-up , use integers in the place of inputs.
- Enter them using enter-record function.
- Then , view it using view-record function.
- then, delete it using delete-record function.
- Finally, if your entered value is deleted , then the program is functioning properly.
